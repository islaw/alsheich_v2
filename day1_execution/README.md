# יום 1 – הרצת מנוע בדיקה ראשוני

בשלב זה אנו מריצים מנוע בדיקה ראשוני להשוואת תפוקות LLM מול קובץ אמת מוחלטת.

## קבצים:
- `ground_truth.json` – אמת מוחלטת
- `llm_extraction_bakeoff_v0.6.py` – מנוע הרצה
- `llm_test_harness_v3.5.py` – מעטפת ניהולית
- `error_traps_v1.0.json` – מערך מלכודות שגיאה

## מבנה תיקייה:
- `data/` – נתוני אמת
- `engine/` – קוד הרצה
- `run_tests.py` – סקריפט ראשי
