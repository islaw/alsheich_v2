**6. עדכון סביבת עבודה - GitHub ו־VS Code**

**6.1. פתיחת חשבון GitHub וחיבור VS Code:** המשתמש פתח חשבון ב־GitHub וחיבר אליו את סביבת VS Code. כל פעולות הפיתוח, הניהול והגרסאות יתבצעו מעתה דרך VS Code, כאשר Git משמש לניהול גרסאות שיטתי ומבוקר.

**6.2. נוהל עבודה חדש:**

* כל הקבצים ינוהלו תחת ריפוזיטוריז של GitHub.
* כל שינוי חייב להתבצע ב־branch ייעודי (למשל `dev`) ולכלול `commit` עם תיעוד.
* כל תחילת סשן תיפתח בבדיקת סטטוס מול `main` ו־`dev`.

**6.3. פקודות בסיסיות (מ־VS Code בלבד):**

```bash
# פתיחת סשן:
git checkout dev
git pull origin dev

# ביצוע שינויים:
git add .
git commit -m "🟢 תיאור ברור של השינוי"
git push origin dev

# סימון שלב משמעותי:
git tag v_dayX_stepY
```
