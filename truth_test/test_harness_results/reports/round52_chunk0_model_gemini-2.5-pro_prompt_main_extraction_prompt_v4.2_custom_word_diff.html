הזו? ת. מ-2009. ש. אוקי. את המספר שלה, או שהזמנתי את מספר ההחלטה או שהזמנתי עם זה? עו"ד עמית חדד: את יכולה להגיד לה ש. מספר 4431 זו ההחלטה? ת. אינני זוכרת את המספר ש. אני רוצה להציג לך שתי חוברות
